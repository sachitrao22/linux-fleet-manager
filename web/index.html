    What the command does

    • Creates a temporary folder with its own Python environment
    • Downloads the agent (read it first) and runs it in that window
    • Runs in safe mode: it reports stats and answers the built-in actions above, and refuses anything else

    • Your sandbox ends after 60 minutes and its data is deleted.

      How it works

      Three parts, all in the repository, with the reasoning in DESIGN_DECISIONS.md.

      An agent on each machine

      A small Python program reads CPU, memory, disk and network every 10 seconds and keeps one WebSocket open to the server. If the connection drops, it keeps measuring and sends the backlog when it reconnects.

      A control plane

      FastAPI and PostgreSQL. Commands are saved before they're sent, re-sent until the device answers, and never run twice. Alerts open, escalate and resolve on their own. It can also reach machines over SSH with nothing installed.

      This dashboard

      Plain HTML and JavaScript calling the same API anyone could. The live server you see is the API's own host, running the agent in safe mode.

      What it saves

      Monitoring a fleet with CloudWatch custom metrics is billed per metric. Self-hosting costs one small server.
